# Demo-Ablage (lokal)

Hier landen hochgeladene `.dem`-Dateien. Der Ordner ist per `.gitignore` vom Repo
ausgeschlossen, Demos werden nicht committet (kein Git LFS).

Upload: über das Web-Formular (`/`) oder die CLI (`cstaktik analyze <datei.dem>`),
siehe `backend/README.md`.

Pro-Demos (spätere Phase) kommen in einen eigenen Ordner, nicht hierher.
